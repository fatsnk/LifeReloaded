### 介绍
此分支是原项目https://github.com/EmbraceAGI/LifeReloaded 的Character Card（酒馆角色卡）移植。
作为安卓移动端项目https://github.com/fatsnk/forksilly.doc 的示例角色卡。如果需要在sillytavern中使用，可能需要修改世界书中random宏。
